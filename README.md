## 🚀 Установка

### 1️⃣ Клонирование репозитория

Скачайте архив с релиза, или же с главной странички репозитория, code > download zip.

Или-же:
```bash
git clone https://github.com/TransmuterEntrance/SNOS_tg
cd sand-snoser
```

### 2️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

💡 Рекомендуется использовать **Python 3.10+**

### 3️⃣ Запуск

```bash
python main.py
```

⏳ После запуска **дождитесь полной загрузки программы**.
Не закрывайте консоль во время инициализации - некоторые компоненты могут загружаться несколько секунд.
